8 · Template & hiệu ứng

Chọn mẫu — màu, font và khung viền của thiệp đổi ngay trong khung xem trước.

Canvas nhẹ 60fps, tối đa 36 hạt trên mobile / 70 hạt desktop (mobile = màn hình ≤640px hoặc máy có cảm ứng), tự dừng khi tab ẩn hoặc khi hệ thống bật giảm chuyển động. DPR giới hạn ở 2.

9 · Nhận RSVP / Lời chúc

Thiệp xuất ra là web tĩnh, không có database riêng — muốn nhận được RSVP thật của khách thì phải chọn một nơi nhận bên dưới. Hướng dẫn từng bước xem docs/RSVP.md.

Lưu ý: thiệp xuất dùng fetch no-cors khi gửi về Apps Script nên không đọc được phản hồi — thiệp chỉ báo “đang ghi vào Sheet” khi gửi đi không lỗi mạng. Luôn lưu thêm 1 bản trên máy khách để khách thấy lời chúc ngay.

10 · Xuất bản cho khách (Push GitHub)

Đẩy thiệp lên repo GitHub qua API, trả về link GitHub Pages sống ngay. Token chỉ gửi tới api.github.com, không gửi đi nơi nào khác.

Nếu đã nhập tên miền, link thiệp trả về sẽ dùng tên miền đó và Builder tự ghi file CNAME ở thư mục gốc của repo. Mở Builder ngay trên tên miền riêng (hoặc bản mirror pages.dev / vercel.app) thì Builder tự nhận tên miền đang mở làm link thiệp.

Token cần quyền: classic PAT với scope repo, hoặc fine-grained PAT với quyền Contents: Read and write trên repo này. Xem chi tiết trong README.md mục “Cấu hình GitHub Token”.

Dữ liệu tự lưu trên trình duyệt này (localStorage). Xuất file HTML hoặc push GitHub sau mỗi buổi làm việc để giữ lại thành quả.
